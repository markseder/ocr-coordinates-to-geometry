# Проверка OCR2Geometry 1.1.0

Тестовая ветка: feature/1.1.0-compact-dms. В main и каталог QGIS пока не публикуем.

Скачайте артефакт ocr-coordinates-to-geometry-windows-latest из GitHub Actions для этой ветки. Распакуйте
архив артефакта и установите вложенный ocr_coordinates_to_geometry.zip через
менеджер модулей QGIS, затем перезапустите QGIS.

1. Откройте исходную таблицу из пяти точек. Проверьте режимы Авто и DMS.
2. Должны появиться все пять точек. Первая: 61°47′00″ / 149°39′07″;
   последняя: 61°45′52″ / 149°36′37″.
3. Если OCR потерял знак градуса, строка будет жёлтой с предупреждением и
   исходным текстом в подсказке. Обязательно сравните её с изображением.
4. Проверьте обратный порядок осей, создание геометрии и CSV.
5. Повторите проверку на старой семиколоночной таблице и таблице DD.

Восстановление допускается только при сохранённом знаке минут и двух цифрах
минут перед ним (например 14943′00″). Строки без достаточных разделителей
не угадываются. Неверные минуты, секунды и пределы координат отклоняются.
Подсказки доступны на русском и английском. CRS выбирается пользователем.
