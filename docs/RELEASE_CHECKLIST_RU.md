# Проверка кандидата OCR2Geometry 1.0.2 в QGIS 4 / Windows

Автотесты проверяют настоящие Qt-таблицы, синтетическую сетку OpenCV и отдельные
процессы. Они не заменяют запуск в настоящем QGIS с RapidOCR.

- [ ] Указать точные версии QGIS, Windows и Python из диагностики плагина.
- [ ] Установить кандидат ZIP и перезапустить QGIS.
- [ ] Вставить DD `1;59.12345678;93.98765432`; переключить секунды 3 → 0 → 6.
      Проверить, что DD и координаты созданной точки не изменились.
- [ ] В ручной таблице заменить широту DD на `91`, затем на `oops` и пустое значение:
      подтверждение должно блокироваться. После исправления ввод должен работать.
- [ ] После неверной широты исправить долготу: ошибка широты не должна исчезнуть.
- [ ] Распознать DMS с минутами `99`, секундами `60`, широтой `90°30′`:
      строка должна остаться видимой и не допускаться к созданию.
- [ ] Распознать строку `1 12.5 44.25 W`: долгота должна быть отрицательной.
- [ ] Распознать обычную таблицу и таблицу с закрытой/нечитаемой ячейкой в последней
      строке. Последняя строка должна остаться; проверить исходный текст в подсказке.
- [ ] Восстановить пустые ячейки или удалить только проверенную лишнюю строку.
- [ ] Выбрать EPSG:3857: создание должно блокироваться. Выбрать EPSG:4326:
      создать точки, линию, полигон и проверить расположение, площадь, подписи.
- [ ] Сохранить CSV и сопоставить DD со свойствами геометрии и исходной таблицей.
- [ ] Проверить номера `1` и `1000000000`: проверка должна быстро показать
      первые 100 пропущенных номеров и их общее количество.
- [ ] Проверить OCR на обычном профиле с установленными зависимостями.
- [ ] В чистом профиле установить OCR и распознать тестовый снимок.
- [ ] При недоступной сети отменить установку: интерфейс должен отвечать.
- [ ] Проверить сохранение настроек и повторный запуск после перезапуска QGIS.

После успешной проверки кандидат можно слить в main для выпуска v1.0.2 и затем
загрузить в каталог QGIS. До этого это проверочная сборка, не подтверждённый релиз.
