# Проверка OCR2Geometry v1.0 на чистой установке

- [ ] Создать новый профиль QGIS или использовать другой компьютер.
- [ ] Убедиться, что RapidOCR ранее не установлен в этом профиле.
- [ ] Установить ZIP `v1.0.0-beta1` и перезапустить QGIS.
- [ ] Установить OCR кнопкой плагина и распознать тестовое изображение.
- [ ] Проверить подсветку достоверности и ручное исправление ячеек.
- [ ] Вставить DMS и DD из Excel без номеров точек; проверить пересчёт.
- [ ] Выбрать исходную CRS и собственное название слоёв.
- [ ] Создать точки, линию и полигон; проверить площадь и периметр.
- [ ] Сохранить CSV и открыть его в Excel/QGIS.
- [ ] Проверить сохранение настроек после перезапуска.
- [ ] Удалить и повторно установить плагин из того же ZIP.

После выполнения сообщите версию QGIS, Windows и результат. Тогда beta будет
переиздана как стабильная `v1.0.0` без изменения набора функций.
