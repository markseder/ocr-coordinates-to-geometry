# Руководство пользователя OCR2Geometry

## Установка

Скачайте ZIP на странице GitHub Releases и выберите **Модули → Управление
модулями → Установить из ZIP**. При первом OCR подтвердите установку RapidOCR.
Изображения и координаты обрабатываются локально.

## Распознавание изображения

1. Откройте изображение или вставьте скриншот и запустите распознавание.
2. Проверьте каждую ячейку: цвет достоверности OCR не гарантирует правильность.
3. Выберите CRS, которой уже соответствуют исходные числа.
4. Задайте базовое название и выберите точки, линию и/или полигон.
5. Проверьте предупреждения, измерения и геометрию перед созданием.

## Ручной ввод и CSV

Откройте **Вставить координаты**, вставьте диапазон из Excel или заполните
ячейки DMS/DD. Оба представления пересчитываются автоматически. Если номера
точек отсутствуют, они создаются последовательно. Проверенную таблицу можно
сохранить кнопкой **CSV**.

Назначение CRS не преобразует координаты. Для другой CRS используйте штатное
перепроецирование или экспорт QGIS.


## Проверки и точность в 1.0.2

- Неверные минуты/секунды и широта/долгота за пределами ±90°/±180° блокируются.
- Настройка знаков в секундах меняет только вид таблицы. При редактировании ячейки
  показывается точное сохранённое значение; геометрия и DD в CSV используют его.
  DMS в CSV округляются согласно выбранному отображению, DD выводятся с 8 знаками.
- После ошибочного ручного ввода зависимые ячейки очищаются. Подтверждение невозможно,
  пока координаты не исправлены. Исправляйте нужную ячейку, а не подтверждайте старые значения.
- Неполные строки OCR остаются красными в основной таблице. Исходный текст доступен
  при наведении на ячейку; заполните координаты DMS или осознанно удалите строку
  после сверки со снимком. Для DD/DM, которые не удалось разобрать, заполните строку
  вручную в DMS. Красный пустой номер точки также нужно заполнить.
- Цвет показывает минимальную уверенность OCR во всей строке, а не вероятность
  правильности конкретной вычисленной координаты.
- Выбирайте географическую CRS в градусах, соответствующую исходным координатам.
  Проекционные CRS и плоские X/Y пока не поддерживаются.
- Во время OCR интерфейс продолжает обрабатывать события. Прерывать отдельный вызов
  движка нельзя, поэтому окно OCR закрывается по завершении обработки.
- Установку OCR можно отменить, даже если pip молчит; общий тайм-аут — 20 минут.
