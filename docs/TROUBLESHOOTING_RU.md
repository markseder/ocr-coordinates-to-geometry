# Решение проблем

- **OCR недоступен:** нажмите **Установить OCR**, дождитесь завершения и повторите.
  Загрузку pip может блокировать прокси или антивирус.
- **Геометрия не на месте:** проверьте порядок осей и исходную CRS. Назначение
  CRS не перепроецирует числа.
- **Вставка попала не в те столбцы:** копируйте только диапазон данных; форматы
  из 2, 3, 7, 8 и 9 столбцов определяются автоматически.
- **Нужна помощь:** скопируйте диагностику из окна «О плагине», обезличьте
  пример и приложите точные шаги воспроизведения к задаче GitHub.
