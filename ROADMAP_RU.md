# Программа разработки

[English version](ROADMAP.md)

План задаёт направление разработки. Функция считается выпущенной только после
реализации, тестов, документации и проверки в настоящем QGIS 4.

## v0.3 — Основа продукта

- [x] Русский и английский интерфейсы и расширяемый каталог переводов.
- [x] Иконка и окончательное название продукта.
- [x] Окно «О плагине», диагностика и ссылка поддержки проекта.
- [x] Сохранение пользовательских настроек.
- [x] Подготовка и проверка пакета для официального каталога QGIS.
- [ ] Набор обезличенных тестовых изображений.

## v0.4 — Форматы координат

- [ ] ГГ° ММ′ СС″, десятичные градусы и градусы с десятичными минутами.
- [ ] Автоматическое определение формата с возможностью ручного выбора.
- [ ] Реверс широты/долготы и координат X/Y.
- [ ] Полушария N/S/E/W и координаты со знаком.
- [ ] Вставка обычного текста с координатами без изображения.
- [ ] Сохранение исходного порядка или сортировка по номеру точки.

## v0.5 — Исходная CRS и названия слоёв

- [x] Выбор исходной CRS из стандартного каталога QGIS.
- [x] Безопасное значение по умолчанию EPSG:4326.
- [x] Пользовательское базовое название создаваемых слоёв.
- [x] Сохранение выбранной CRS и названия между запусками.
- [x] Преобразование координат оставить штатным инструментам QGIS.
- [ ] Проверка v0.5.0 в QGIS 4.0 на Windows 10/11.

## v0.6 — Контроль качества

- [ ] Уверенность OCR для каждой ячейки и подсветка сомнительных значений.
- [ ] Поиск пропущенных, повторяющихся и аномальных вершин.
- [ ] Проверка самопересечений и корректности кольца.
- [ ] Площадь и периметр, сравнение со значениями из документа.
- [ ] Отчёт об исходных и исправленных значениях.
- [ ] Отмена или удаление последнего созданного результата.

## v0.7 — Документы и пакетная обработка

- [ ] Загрузка страниц PDF и выделение области таблицы.
- [ ] Несколько таблиц в одном документе.
- [ ] Пакетная обработка изображений и папок.
- [ ] Шаблоны для повторяющихся форм документов.
- [ ] Экспорт GeoPackage, SHP, DXF, KML и GeoJSON.

## v0.8 — Расширение и интеграция

- [ ] Алгоритм для панели Processing.
- [ ] Интерфейс подключения дополнительных шаблонов распознавания.
- [ ] Интеграция с OreScope: документ → координаты → месторождение.
- [ ] Общие настройки для организаций.
- [ ] Дополнительные языки интерфейса от сообщества.

## v1.0 — Стабильный выпуск

- [ ] Стабильный API и документированная модель данных.
- [ ] Автоматические тесты совместимости с поддерживаемыми версиями QGIS.
- [ ] Воспроизводимая сборка и перечень зависимостей.
- [ ] Полное руководство пользователя и диагностика ошибок.
- [ ] Правила миграции и долгосрочной поддержки.

## Обязательные принципы

- Локальная обработка по умолчанию.
- Проверка человеком до создания геометрии.
- Никаких скрытых предположений о CRS и датуме.
- Воспроизводимые преобразования и проверяемый результат.
- Парсер развивается на основе реальных документов.
