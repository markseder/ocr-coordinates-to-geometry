# Contributing

[Русский](#русский) · [English](#english)

## Русский

Особенно полезны обезличенные примеры таблиц координат, точное описание
ожидаемого результата, версия QGIS и Windows, снимок ошибки и информация об
исходной системе координат.

Не публикуйте координаты ограниченного доступа, персональные данные, номера
действующих лицензий или внутренние документы организации без разрешения.
Замените чувствительные цифры, сохранив структуру таблицы и качество изображения.

Сообщение об ошибке должно содержать один воспроизводимый пример. Новую функцию
лучше описывать через реальную задачу: какой документ поступает и какой слой или
файл должен получиться.

## English

The most useful contributions are sanitized coordinate-table samples, an exact
expected result, QGIS and Windows versions, an error screenshot and source CRS
information.

Do not publish restricted coordinates, personal data, active licence identifiers
or internal company documents without authorization. Replace sensitive numbers
while preserving the table structure and image quality.

Bug reports should contain one reproducible example. Feature requests are most
useful when they describe the real input document and expected output.
